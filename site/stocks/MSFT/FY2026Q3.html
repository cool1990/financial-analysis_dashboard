行业展望

需求变化

管理层称 Azure 在各类负载、客户群和地区的需求持续超过可用产能，供给约束预计至少持续到2026年。商业剩余履约义务升至6270亿美元，同比增99%，约25%将在未来12个月确认，同比增39%；剔除 OpenAI 后增26%。AI 业务年化收入超370亿美元，增123%。

  • M365 Copilot 付费席位超2000万，席位新增同比增250%，Q4净新增席位预计环比增加
  • GitHub Copilot 订阅企业数同比近3倍，Copilot 使用强度达到与 Outlook 相当
  • Dynamics 365 因客户在按席位与席位加消费间权衡，续约偏弱，Q4增速预计降至低双位数

供给变化

Q3新增约1吉瓦容量，计划两年内将整体规模翻番。Fairwater 威斯康星数据中心提前6周上线。Q4资本开支升至400亿美元以上，2026日历年约1900亿美元，其中约250亿美元来自零部件涨价。管理层称Q4增量约50亿美元为组件价格因素，并强调短期资产（GPU、CPU）与营收最相关。

  • 自研 Maia 200 已在爱荷华与亚利桑那上线，每美元 token 数提升30%以上
  • Cobalt CPU 部署在近半数数据中心区域，并将大幅扩供
  • 新 GPU 在最大区域的上架时间缩短近20%，推理吞吐提升40%

竞争变化

微软强调提供最广泛的模型选择（OpenAI、Anthropic、开源）。超1万家客户在 Foundry 使用多个模型。更多个人计算受 PC 市场（内存涨价）影响：Q4 Windows OEM 下滑受上年 Win10 终止支持基数、库存回落和 PC 市场萎缩影响各约6个百分点。Edge 连续20个季度份额增长，必应月活首次达10亿。

商业模式

管理层反复强调从按席位向“席位+消费”转型，认为生产力、编码、安全等按用户业务都会变为按用户加按使用量。席位相当于一定消费的权益，超出部分按消费计费，长期承诺有折扣。订单可能因此不完全体现在订单指标里，短期订单（剔除 OpenAI 后增7%）会受影响。GitHub Copilot 将在6月1日转为按使用量定价，约60%的客服类客户已购买用量积分。

公司战略（OpenAI 与利润率）

新协议下微软拥有至2032年的前沿模型 IP 权利且免版税，收入分成延续至2030年，同时取消微软向 OpenAI 的分成，OpenAI 同时是大客户。Amy 认为 AI 利润率好于云转型周期，来自使用量计价、免费 IP、自研硬件与效率提升。Q4微软云毛利率预计约64%，主要受 AI 投资与 GitHub Copilot 使用增加影响。
