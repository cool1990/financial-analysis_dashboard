行业展望

外部环境（技术变化）

Andy 认为全球 IT 支出大约 85% 仍然在本地部署，云化迁移会是一个 10 到 20 年的长周期。过去大家认为大型机、存储区域网络这类关键负载永远不会上云，但现在 AWS 已经做出云替代方案和 AI 驱动的迁移能力，这些负载正在加速上云。

在 AI 方面，Andy 强调企业把推理大规模用于生产应用还非常早期。限制因素包括企业里懂得如何操作 AI、做后训练和微调模型的人还不够多，以及推理成本仍然偏高。AWS 把持续降低推理成本当作重要任务，这也是自研 Trainium 芯片的核心原因之一。

Andy 还提到，随着前沿模型能力变强，它们正在以人类过去没有的速度发现软件漏洞。有人预计未来一两年内，安全场景可能占全部 token 用量的相当比例，甚至可能达到 20%。这是继编程、AI 助手之后新出现的大规模使用场景。

需求变化

AWS 需求非常强劲。Andy 说公司大约每 14 秒就安装一台 AI 加速器，而且几乎刚装好就被客户用满。AWS 积压订单达到 5780 亿美元，同比增长三位数，并且分布很广。

AI 推理需求增长很快，推理已经占 AWS AI 收入的一半以上，而且还在增长。Andy 认为企业生产应用未来几乎都会被改写成具备智能体能力，这会带来大量新的 AI 用量。

零售端，Andy 指出全球零售仍有近 80% 发生在实体店，未来会逐步转向电商。亚马逊正在通过更快的配送网络推动这一转变。日用必需品和生鲜需求增长明显，Q3 生鲜和 Everyday Essentials 增速大约是其他品类的三倍，占全部销量约一半。

Alexa for Shopping 过去 12 个月有超过 4 亿客户使用，互动量同比增长 570%。美国使用该助手的客户每单消费比不用的人高 50%。

供给变化

AWS 在持续大量增加算力供给，但每个季度新增容量并不均匀。Andy 说大客户会提前锁定数百兆瓦甚至高达 1 吉瓦的容量，因此公司对 2027、2028 年以及部分 2029 年的大块容量需求有很好的可见度。

自研芯片供给能力在增强。Graviton 和 Trainium 的收入承诺同比都增长超过 20 倍。客户使用自研芯片在 Q3 节省了超过 20 亿美元。Graviton5 发布后，上一代 Graviton 实例的积压订单环比仍翻了一倍多；上一代 Trainium 实例的短期容量价格也比上半年更高。

Andy 表示，由于 Trainium 需求太强，客户一直鼓励亚马逊把它卖到 AWS 之外，公司计划在 2027 年底开始对外销售 Trainium 芯片。

零售履约方面，亚马逊 2026 年把 Cardinal、Sparrow 等机械臂数量翻了一倍，并正在开发机器人基础模型，目标是更快编程、让机器人学会更复杂的物理任务，最终规模化部署。

竞争变化

Andy 认为 AWS 的模式不同于主要靠托管 GPU 或短期出租数据中心容量的做法。AWS 是长期平台策略，靠领先的功能、安全和运营表现吸引客户，客户把应用和数据放在 AWS 后，又会带动 AI 需求，AI 再带动核心计算、存储需求，形成飞轮。

在芯片价格性能上，Andy 说 Graviton 比 x86 方案有 30% 到 40% 的价格性能优势，Trainium 相对其他 AI 加速器也有明显价格性能优势。随着企业开始大规模部署推理，客户对节省成本非常敏感，这成为 AWS 的竞争抓手。

零售方面，Andy 说亚马逊的增长明显快于其他零售竞争对手，在美国每季度新增的毛销售额大约是第二大竞争对手的两倍，并持续抢占零售市场份额。

在购物智能体上，Andy 认为外部横向智能体对亚马逊广告影响不大，因为目前很少有客户这样购物，体验还不够好，也不比直接到零售商那里研究或一键下单更方便。

商业模式

AWS 的商业模式是平台型长期收费，而不是单纯卖算力。客户在 AWS 上运行应用、存储数据，随后使用 Bedrock 做推理、用 AgentCore 构建智能体，再带动核心计算、存储和网络消费。Andy 说这种模式无论供给是否紧缺，都能带来有吸引力的长期经济回报。

Bedrock 是 AWS 历史上增长最快的数十亿美元级服务。Fortune 500 公司在 Bedrock 上的支出同比增长近 7 倍，Bedrock 总 token 量同比增长近 17 倍。Bedrock 的卖点包括安全：输入和输出不会共享给模型提供商，也不会被用来训练基础模型。

自研芯片也是商业模式的一部分。客户使用 Graviton 和 Trainium 可以显著降低成本，AWS 还计划在 2027 年底把 Trainium 卖到 AWS 之外，开辟芯片外销收入。

零售端，Andy 强调生鲜和 Everyday Essentials 是提升客户钱包份额的关键。购买生鲜同日达的客户，购买 Everyday Essentials 的数量是其他人的近 7 倍；活跃生鲜客户购买非生鲜品类的频率是其他人的近 4 倍，支出是 2 倍以上。

广告方面，亚马逊推出 Amazon Ads Agent，把赞助广告、展示广告、视频和流媒体电视整合到一个 AI 优先平台里。广告主提供预算和时长，AI 负责规划、执行和持续优化。

公司战略

Andy 把 AWS 的战略描述为一个飞轮：领先的功能、安全和运营表现，驱动客户把应用和数据放到 AWS；客户数据和应用靠近生产推理，又驱动 AWS AI 需求；AI 使用核心服务做强化学习、后训练和工具调用，再驱动核心 AWS 需求；核心增长又反过来支持继续投资 AWS 功能。

  1. 继续扩大 AI 和核心服务功能：Bedrock 加入 OpenAI、Kimi、GLM、SpaceX 等模型，推出 AWS Continuum 安全服务，并把它集成到 Claude Code、OpenAI Codex 和 AWS Kiro 中，目标是让客户在 AWS 内完成从开发到安全的全部工作。
  2. 用自研芯片降低客户成本并形成差异化：Graviton 主打 CPU 价格性能，Trainium 主打 AI 训练和推理价格性能，并开源 TorchNeuron，让开发者不用改写现有 PyTorch 代码就能在 Trainium 上运行。
  3. 把 Trainium 卖到 AWS 之外：计划 2027 年底开始外销，满足市场对高价格性能 AI 芯片的需求，同时扩大芯片业务的收入来源。
  4. 在零售端继续投资提速和降本：扩大当日达网络、Amazon Now 和 Prime Air，Q3 向 Prime 客户交付了超过 15 亿件当日达或次日达商品；同时连续第四年降低单件服务成本，以便继续匹配或低于竞争对手价格。
  5. 用生鲜和药房提高客户粘性：Amazon Now 已覆盖超过 450 个城镇，订单量同比增长 10 倍；Amazon Pharmacy 客户数同比增长超过 60%，并在超过 350 个城市提供三小时处方配送。
  6. 把 Alexa for Shopping 打造成主要购物智能体：利用客户历史购买、地址和支付信息，提供研究、比价、价格历史和降价跟踪，目标是成为客户在亚马逊购物的主要入口。
