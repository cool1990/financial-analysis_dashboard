Brian NowakMorgan Stanley Brian Nowak 问 Muse 用户增长最受哪些约束（能力、模型效率或产能），以及 Meta Enterprise 近期要提供什么。 产品结构

答：Mark 先讲 Muse 的用户增长。美国和加拿大已有超过 1000 万人在上线后的前 6 周完成设置，但这项服务很吃算力，所以还没有全球开放；原因既包括各地要做优化和连接器，也包括必须先把效率做到能够服务他认为有可能超过 10 亿人的规模。他说算力效率会是未来一年的限制因素，业务建设和效率提升要一起做。产品上，免费档目前默认仍是 Muse Spark，付费档已经可以用来表现更好的 Muse Wonder，他们正在做能更广铺开的省算力版本。他预期再迭代两三代表现和价格都会更好，从而释放更多用户价值。

we have more than 10 million people in the US and Canada who have set it up

新数字：more than 10 million（美国和加拿大已设置 Muse 的人数，出现在这句回答里）

Brian NowakMorgan Stanley 同一轮里，Brian Nowak 请 Mark 说明 Meta Enterprise 的产品设想和对企业客户的价值。 产品结构

答：Mark 说近期主要的企业产品是模型 API 和 Muse code，商业 agent 已经做了一段时间，这三块都增长很快。他看到不少人已经用 Muse 经营小企业，因此既想做一个能帮人把开业里费时、但不是核心的工作自动化的 agent，也想做一个可以带进不同公司环境的 Muse。更长期是他所说的 Muse network：不只是每个人自己的 Muse，而是能和亲友的 Muse 协作，购物时直接和企业的 agent 对话。Susan 补充，传统企业软件公司并没有锁死这个市场，一些今天领先的公司几年前还不存在；Meta 同样做了模型投入，并已有 5 亿家企业在用公司的产品。她预计各种规模的企业会把 AI agent 用在软件开发、效率、销售、营销和客服上。公司希望这成为新的、可以多元化的经常性收入，覆盖订阅、按用量计费的 API、消息和其他收入，并按已经验证的客户需求和产品市场匹配来加大投入。她把这看作一个要发展多年的机会。

the main enterprise offering in the near term is going to be the model API and Muse code
Eric SheridanGoldman Sachs Eric Sheridan 问，如果平台或供应商不愿让 agent 接入，公司如何降低 agentic commerce 的摩擦。 客户与订单部分回答

答：Mark 说眼下看到的是企业普遍很积极，因为这既能提高现有客户的销量和体验，也可能带来新客户。不同企业的采用节奏会不一样，公司的做法会跟着调整。他认为超出预期的是，很多企业不仅想让 Muse 更好地调用自己的服务，还主动来谈接入。Susan 补充，也有企业在意保护自己的客户关系。她预计市场会从 agent 像人一样去浏览每一个界面，转向有授权的结构化交互，包括经过认证的 API、获准的 agent 合作，以及消费者的个人 agent 与企业自己的 agent 直接通信。本月早些时候，公司与 Sierra、Walmart、Stripe、Shopify 等行业伙伴预览了跨 Muse 和 Meta business agents 的个人 agent 协议和开放标准，用来规定两边如何安全、可靠地交互，并给企业和客户保留适当控制。她说采用会不均衡、需要时间，近期很多体验仍会是 AI 辅助而不是完全自主；等可信接入能证明增量需求、并且运行安全，更多企业会愿意参加。她没有点名不愿接入的对象，也没有给时间表。

Justin PostBank of America Justin Post 问新模型用到广告系统后，还有多少改进空间。 指引与展望部分回答

答：这问原本是问 Mark 的，Susan 说两问都由她来答。她把广告系统还能改进的空间分成三块。第一是原有的效果改进路线，也就是日常的机器学习工作，她说这条管线仍然健康；因此虽然公司不提供 2027 年展望，广告和互动上的投入仍让她相信核心业务在 2027 年有实质的增长空间，但她没有给幅度。第二是转向更偏大语言模型的基础设施，用来更深入理解人们对自然内容和推荐的偏好，并期望由此改善排序和推荐。第三是生成式工具继续通过 Advantage Plus 给广告主增加功能，例如由图片生成视频或生成声音，让广告更针对被投放的人。她说这三块都还有空间。

Mark ShmulikBernstein Mark Shmulik 问公司内部是否已把 Muse 放在一切的中心，业务目标是否因此改变。 产品结构部分回答

答：Mark 没有直接确认 Muse 已经是一切的中心。他说一年多前写过一封信，把个人超级智能当作这项工作的北极星，并把它接上公司二十多年以来赋能个人、给人表达和连接工具的方向。延伸到 AI，就是把这项技术交到每个人手里。重启 MSL、建立实验室，很大一部分是因为需要专门把模型做成个人 agent，并由自己掌握从模型到 agent 的端到端体验。眼镜也是同一思路：做下一代硬件平台，把端到端体验交给用户。他认为这已经开始成形，未来几年会更明显。这些是长期赌注；只要继续为全球数十亿人设计体验并执行好，业务会跟着起来。他没有改口说各项业务目标已经因此改变。

未回答的部分：没有确认 Muse 已是一切的中心。

Mark ShmulikBernstein Mark Shmulik 问要把 Muse 做到小型企业，还需要哪些工作。 客户与订单
