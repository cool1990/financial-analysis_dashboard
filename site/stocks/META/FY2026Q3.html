行业展望

外部环境（技术变化）

Mark 认为 AI 领域发展很快，而且只要把模型继续做大，就能做出超级智能，所以 Meta 会"一步步往上爬"，已经在做比 Muse Wonder 更大的模型。他还看到一个年年出现的规律：一年后，用更小的模型、只花一小部分成本，就能达到今天 Muse Wonder 或任何现有前沿模型的水平。他预计 Muse 的成本效率明年能提升 10 倍以上，并认为之后几年继续快速提升"非常可能"。另外，模型越聪明，产品就越好用，Muse Wonder 已经让质量、互动和留存都进一步提升。他还说，公司正在测试用 Muse Wonder 自动改进推荐和广告系统，预计模型越强，改进速度越快。

需求变化

他认为个人 AI 助手（agent）的需求很强。Muse 只在美国和加拿大上线一个半月，就有超过 1000 万人设置，约 25% 每天使用，起步水平是 Threads 的两倍多，他认为也高于其他 AI 应用起步时的水平。如果全球上线，用户数会大得多。

需求主要来自购物。超过四分之一的用户用 Muse 购物，平均每单 200 美元以上。交易量大到第一周就要和 Stripe 一起上调信用额度。其次是连接邮件、日历等个人效率用途。也有不少人用 Muse 帮自己经营小生意。

商家这边，他说绝大多数商家很积极，认为这能提高销量、改善客户体验，甚至带来新客户，很多商家主动找 Meta 做对接，"超出预期"。但不同商家接受的快慢不一样。

他也指出，需求标准会不断提高：一年后，大多数人不会满足于今天的智能水平，因为模型也在进步。

供给变化

他说目前最大的限制是算力。Muse 运行很耗算力，所以还没有全球上线，要先把效率做上去才能放量，这会是未来一年的主要制约之一。公司正在建设能服务 10 亿以上用户的算力，前提是达到一定的效率目标。

在他看来，训练模型是一笔巨大的固定成本。既然已有领先模型，就要把它卖给尽可能多的高利润用途来摊薄成本，比如对外提供模型 API、编程工具 Muse Code 和其他企业服务。他还说，公司还没找到算力用于提升自家核心业务的上限。

竞争变化

Mark 认为，要做出最好的个人 agent，必须自己掌握模型、agent 和硬件整条链路。Muse Wonder 在多个关键维度领先，证明了自己训练模型的重要性。他认为 Meta 是推行这一战略"位置最好的公司"，世界上很少有公司能像 Meta 这样做，因为核心业务足够强，可以先投入把 Muse 网络做起来。此外，他提到 Threads 的月活已超过 X。

商业模式

他认为购物方式会变：以后买东西不再是打开商家网站，而是让你的 Muse 和商家的 agent 直接对话。Muse 也不再是一个人用的工具，而是能和亲友、商家的 Muse 协作的网络，参与的人和商家越多，网络越有价值。所以 Meta 不打算一开始就向所有人收费。

具体收费方式有四种：

  • 大多数人免费使用，Meta 按促成的交易收取费用，预计由商家承担。
  • 想用最先进模型或更多用量的个人，付费订阅。
  • 想用 Muse 增长业务的商家，以及想让员工用 Muse 工作的公司，付费订阅。
  • 用户可以把 Muse 连接到 Meta 的内容和广告体验上，帮助改善个性化。

他预计，Muse 用户长期带来的人均收入会高于现有应用在美国每人每年几百美元的水平。硬件方面，眼镜定价不追求在硬件上赚大钱，而是靠在上面长期做软件和 AI 服务赚钱，接入 Muse 后预计付费订阅会增加。

公司战略

  1. 主线是"个人超级智能"：给每个人一个强大的个人助手。Mark 说这既是使命也是策略，目标是尽快服务数十亿人。
  2. Muse 进入运营阶段：已经找到产品市场契合，接下来做三件事：扩大用户规模、增加收入、降低算力成本。
  3. 模型两条线一起走：一边做更大的前沿模型，一边做更小、更高效、专为个人 agent 优化的模型。
  4. 做企业业务：由 CJ Desai 带领 Meta Enterprise 平台，近期主要是模型 API、Muse Code 和商家 agent。长期目标是可以带进企业环境使用的 Muse，以及商家 agent 网络。
  5. 硬件转向 AI 优先：Reality Labs 的重点转向个人超级智能，Muse 下个月登陆 Meta 眼镜。VR 只在有重大突破时才发新设备，投入放慢。他预计 Reality Labs 明年亏损降到约 150 亿美元，之后向盈利方向发展。
  6. 多条路同时下注：Muse 网络、企业平台、用模型加速核心业务，三者的增速很难准确预测，所以同时推进，提高其中一条大幅超预期的概率。
  7. 追求速度：用小团队快速出产品。Muse 从想法到成功产品只用了约 8 个月。
