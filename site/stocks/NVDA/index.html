行业展望

需求变化

Colette 认为需求仍在加速，而且明显超过供给。她提到，即使在过去一周，大客户还在不断追问怎么能拿到更多供给，以满足眼前的 agentic 解决方案和新模型需求。她判断这种需求不会只停留在 2027 年，还会延续到 2028 年，因为积压的需求会继续往后滚动。

需求来源很分散，包括超大规模云厂商、前沿实验室、AI 原生公司、企业和政府。前沿实验室今年预计贡献约 15% 的数据中心收入。Anthropic 的年化收入到 10 月底已经达到 810 亿美元，说明前沿模型商业化在快速放量。

开放模型和 agentic 工作负载在明显拉动需求。OpenRouter 的每周 token 量同比增长 35 倍，仅过去三个月又增长 3.5 倍，其中约 80% 是 agentic 工作负载。Meta 的 Muse agent 在 NVIDIA 基础设施上推出后，六周内在美国和加拿大就超过 1000 万次设置。Colette 说 agentic AI 对 CPU 的需求也远超供给，Vera CPU 已经被 CoreWeave、Meta、Nscale 和 OpenAI 采用，预计 2028 财年 CPU 收入会翻倍以上。

需求还体现在价格和利用率上。token 价格自 5 月以来下降近 60%，反而加速了 token 使用和对算力的需求。Hopper GPU 在多年协议下重新签约的价格最高达到原价两倍，B300 的价格自推出以来上涨超过 60%。NVIDIA 计算资源在所有服务的超大规模云厂商和 neocloud 中都保持满负荷利用。

供给变化

Colette 明确说需求继续超过供给，公司正在和供应商一起加速扩产，重点是晶圆、基板和先进封装。本季度新增了与 Kinsus、三星电机在基板方面的协议，以及与 SPIL 在先进封装方面的协议，此前还宣布了与 Amkor、KYEC 和 Unimicron 的合作。

供给扩张的信心也反映在采购承诺上。Q3 采购承诺增加到 3900 亿美元，Colette 说这代表公司对 NVIDIA 基础设施长期需求可持续性的信心。数据中心租赁和云服务承诺合计略超 1000 亿美元，主要来自长期租赁。与 neocloud 协议相关的承诺到 Q3 末为 320 亿美元。

在产能落地方面，SB Energy 的计划按轨道推进，容量预计从 2028 年开始分阶段上线。PORTS-Pike 园区将独家承载 NVIDIA 基础设施，并通过 20 年租约提供给 OpenAI。Colette 强调，公司会继续和基础设施资本伙伴合作搭建融资平台，但在未来投资、承诺和担保上会更加严格评估。

供给约束也影响分配。Colette 说分配时会优先看客户的 land、power and shell 是否已经准备好，以及资本是否到位。所有客户拿到的价格相同，不会因为类型不同而区别定价。公司会继续在供给增加后加快分配。

竞争变化

Colette 没有把竞争描述成份额压力，而是强调 NVIDIA 的差异化来自全栈协同设计。她说公司在计算、网络、系统、算法和软件上的协同设计能力无人能及，能够按年度节奏带来每瓦性能和每美元性能的跨越式提升。在 MLPerf Endpoints 基准上，Vera Rubin 相比 GB300 每瓦 token 数提升 10 倍。

网络和光学技术也被她用来证明竞争壁垒。Q3 网络收入超过 210 亿美元，共封装光学路线按计划推进，CPO 规模出货已进入量产。Lambda 在 Supercomputing 26 上宣布首个 NVIDIA Photonics CPO 交换机生产部署，连接超过 1 万个 GB300 GPU。与可插拔光模块相比，NVIDIA Photonics 交换机功耗效率提升 5 倍，可靠性提升 15 倍，延迟降低 10%。

在客户自研 ASIC 的问题上，Colette 回应毛利率和定价时表示，NVIDIA 的系统和路线图是世界级的，系统里所承载的能力非常重要，定价经过深思熟虑。她没有承认需要靠大幅压缩毛利率来防守竞争，而是说 2028 财年的毛利率预期与上季度沟通一致，目前没有变化。

商业模式

NVIDIA 的收入模式仍然以出售基础设施为主，同时通过 neocloud 协议参与租赁收入的上行。Colette 解释，在 neocloud 协议下，公司先从基础设施的前期销售中获得收入，并在超过最低承诺的租赁收入中参与分成。Q3 末与 neocloud 协议相关的承诺为 320 亿美元。

公司还在扩大开放模型生态，把它作为带动算力需求的手段。9 月宣布收购 Hugging Face，该平台服务超过 1800 万开发者和 20 万家公司。Colette 说 Nemotron 已经成为 OpenRouter 上使用最广泛的美国开放模型，也是开发者构建自有智能的起点。微软、Salesforce、Palantir、CrowdStrike、Cadence 和 Synopsys 等企业软件和安全公司都发布了基于后训练开放模型的领域专用产品。

在安全与 agent 控制方面，NVIDIA 推出了 Open Agent Safety Platform，并与 100 多家伙伴一起发布。OpenShell 通过限制 agent 对文件和工具的访问来约束行为，NVIDIA Sentry 运行在 BlueField-4 上，在芯片层面监控行为，能在毫秒级阻止 agent 越界。Anthropic、AWS、CoreWeave、CrowdStrike、Dell、Google Cloud、HPE、IREN、JPMorgan Chase、Lenovo、Microsoft、Nebius、OpenAI 和 SpaceX AI 等公司都在合作名单中。

DSX POD 是新的模块化 AI 工厂参考架构，把整集群部署时间从几个月缩短到几周。Colette 用数字说明商业价值：一个 1 吉瓦 AI 工厂年收入接近 500 亿美元，如果能提前一个季度达到 first token，运营商就能多产生超过 100 亿美元收入。公司计划明年初向美国和欧洲中部的客户交付首批 POD。

公司战略

Colette 把公司战略概括为：保持多年领先路线图、锁定到 2030 年的供应协议、以及可持续的需求。她说公司的雄心、创新热情和对客户、伙伴、股东的承诺都不会改变。

  1. 继续扩产并锁定关键供应：新增基板和先进封装供应商，采购承诺提高到 3900 亿美元，目的是让供给跟上仍然超过供给的需求。
  2. 支持开放模型生态：收购 Hugging Face，推动 Nemotron 成为开放模型入口，让每个国家、公司和行业都能构建自己的智能，从而扩大算力需求飞轮。
  3. 推进 agent 安全平台：通过 OpenShell 和 NVIDIA Sentry 提供 agent 行为控制，目标是让 agent 运行更久、更自主时仍然安全可控。
  4. 用 DSX POD 缩短部署周期：把 AI 工厂从机架级组装延伸到整集群模块化交付，帮助客户更快产生收入，也加快 NVIDIA 基础设施的落地速度。
  5. 在资本配置上优先供应商和关键客户：优先支持供应商扩产，对 land、power and shell 等关键资产提供有选择的融资或担保，同时继续执行 1500 亿美元回购计划，目标在 2028 财年末前完成。

在领导层过渡上，Harvey 说董事会已经聘请 Heidrick & Struggles 负责寻找永久 CEO，会同时考虑内部和外部候选人。董事会认为新 CEO 需要应对先进芯片技术和国家安全动态带来的市场变化，因此会彻底搜索，但不会为了赶时间而选错人。
